## Findings

| Tag | Finding | Repository decision |
|---|---|---|
| already_present | Script → visual beat → endpoint frames → motion prompt gives each clip one readable state transition. | Keep persisted audio-driven N+1 plan. |
| implement | A subject reference must remain the same identity across the first establish and any meaningful final return. | Contextual anchor gets its own roster identity, prompt hash, appearance contract and sheets. |
| already_present | Generate in beat order and review/reject weak frames rather than trusting first output. | Keep sequential keyframe admission and resume provenance. |
| already_present | Match visuals to narration and use SFX only on real physical events. | Keep audio-driven blocks and provenance-gated SFX. |
| present_but_wrong | The former terminal return reused the first mechanism subject, not necessarily the viewer-facing context. | Split contextual and mechanism anchors. |
| reject | Random slide/camera transitions and blended transitions obscure causality. | Hard cuts only; no xfade, morph, slide or cross-dissolve. |
| reject | Exaggerated faces, spoken characters, generated pointer text, and auto-generated captions conflict with the project contract. | Closed/neutral mouths; ASS captions only; no generated text. |
| reject | Title/caption hits and ubiquitous zoom/shake are attention effects rather than physical proof. | Reject caption-emphasis SFX and suppress terminal payoff/tail reframe, punch and shake. |

## Applied shot grammar

Open with a contextual subject only where it puts the viewer into a meaningful subject,
then hard-cut into one causal mechanism per clip. Return to the contextual subject only
on the final block when a readable physical proof resolves the final narration claim.
For the stomach example, the final same-torso cutaway shows calm digestion with intact
wall/lining; it is not decorative and it is not a microscope-to-human morph.
