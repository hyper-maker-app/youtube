# Archived prompt-study fixtures

The JSON files in this directory preserve pre-storyboard prompt experiments and may contain
the former camera-journey / phase-annotation language. They are fixtures for comparison
only; `main.py`, `pipeline.py`, and new production runs do not load them as creative input.

New work is governed by the persisted provider-native `TimelinePlan`, `NarrativePlan`, and
per-shot `SceneCard` contract. Do not copy the archived fixed-arc or automatic VFX rules
back into an active production prompt.
